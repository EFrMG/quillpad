# PR #11: Rewrite storage on top of SQLite

[PR #11](https://github.com/someonesalter/quillpad/pull/11) moves notes into a SQLite database and searches them with FTS5.

## Recommendation

Close it, with thanks, unless the maintainers want to give up plain-file storage.

## The case for

Search on 8,000 notes goes from about a second to instant. [issue #26](https://github.com/someonesalter/quillpad/issues/26) shows that slow search is a real complaint.

## The case against

The README says notes "stay readable without quillpad". After this change the Markdown file is a copy that the tool no longer reads:

```python
def load_all():
    from quillpad import db

    return db.load_all()
```

A note edited by hand is not picked up, and there is no migration for existing directories.

## What would change the call

A benchmark against [PR #18](https://github.com/someonesalter/quillpad/pull/18), which keeps plain files and adds an index. Nobody has run one.
